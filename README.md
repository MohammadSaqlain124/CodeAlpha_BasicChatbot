# 🤖 Basic Chatbot (Python)

This is a simple rule-based chatbot built using Python as part of the CodeAlpha Internship.

## 🚀 Features
- Responds to user inputs like greetings and questions
- Continuous chat until user exits
- Simple and clean function-based structure
- Beginner-friendly chatbot logic

## 🛠️ Technologies Used
- Python (if-elif, functions, loops, input/output)

## ▶️ How to Run
1. Download the file
2. Run:
   python chatbot.py

## 💡 Example Inputs
- hello
- how are you
- what is your name
- bye
